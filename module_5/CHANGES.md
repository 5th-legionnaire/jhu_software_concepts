# Change Register: Module 4 to Module 5

Every design change from Module 4 has one row here. The README's
[Changes from Module 4](README.md#changes-from-module-4) section carries one
subsection per row, anchored `#chg-XX`, giving the problem, the decision, and
the trade-off accepted.

`scripts/check_change_register.py <N>` (gate check G7) enforces this table. For every row
whose phase is at most N it requires:

- **Status** is `done`.
- **Rationale** is not empty.
- `README.md` contains the `chg-XX` anchor.
- Every test reference in **Verified by** resolves against `pytest --collect-only`.

A test reference is a backticked `file.py::name` or `::name`, where `::name` reuses
the previous file. `*` and `[*]` match any test name or parameter ID, and a bare
`file.py` must collect at least one test. A row with no test reference must open its
**Verified by** cell with `Evidence:`.
